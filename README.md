# Практика 2. Источники данных

Минимальный загрузчик данных для проекта по экологическому мониторингу.

## Состав файлов

- `ingest.py` — загрузка данных EEA и Open-Meteo, проверка ответов, сохранение файлов и журналирование.
- `config.json` — период, город, загрязнитель, координаты и параметры источников.
- `requirements.txt` — единственная внешняя библиотека `requests`.
- `.gitignore` — исключение виртуального окружения и загруженных данных из Git.

## Требования

Python 3.11 или новее и подключение к интернету.

## Установка и запуск в Windows CMD

```cmd
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python ingest.py
```

Повторный запуск выполняется той же командой `python ingest.py`.

## Что загружается

- EEA: почасовые измерения PM10, Польша, город Warsaw, январь 2022 года; проверенный набор E1a (`dataset = 2`), ZIP с файлами Parquet.
- Open-Meteo: почасовые исторические погодные данные для координат 52.22, 21.00, январь 2022 года; JSON.

Период и параметры источников можно изменить в `config.json`.

## Результаты

- `data/raw/eea/` — исходный ZIP-архив EEA.
- `data/raw/open_meteo/` — исходный JSON Open-Meteo.
- `data/meta/load_journal.sqlite` — журнал запусков, операций и реестр загруженных месячных партиций.

Загрузчик проверяет ZIP-архив и наличие в нём Parquet-файлов EEA; для Open-Meteo проверяет почасовой массив и длины запрошенных рядов. Файлы сначала записываются во временный файл и только после проверки перемещаются в постоянный каталог.

Повторный запуск проверяет наличие сохранённой партиции и её SHA-256. Неизменившиеся файлы пропускаются. Для временных сетевых ошибок, HTTP 429 и ошибок сервера выполняются повторные попытки. Ошибка одного источника не отменяет попытку загрузить второй.

## Комментарий к набору EEA

В документации EEA от 5 мая 2026 года значение `dataset = 2` обозначает проверенные данные E1a за 2013–2022 годы. Поэтому демонстрационный период выбран в пределах 2022 года. Архив EEA может содержать несколько Parquet-файлов по станциям и точкам отбора проб. Полная очистка, отбор окончательного набора станций и объединение с погодой выполняются на следующей практике.
