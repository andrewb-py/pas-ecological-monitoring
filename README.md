# Практика 3. Обработка данных

Скрипт `process.py` обрабатывает исходные файлы EEA и Open-Meteo, полученные на предыдущей практике.

## Файлы

- `process.py` — формирование слоёв Bronze, Silver и Gold.
- `processing.json` — пути к исходным файлам и описание целевой станции.
- `requirements.txt` — библиотеки для чтения и записи Parquet.
- `.gitignore` — исключает локальные данные и виртуальное окружение из Git.

## Запуск в Windows CMD

Сначала должна быть выполнена загрузка данных командой `python ingest.py`.

```cmd
python -m pip install -r requirements.txt
python process.py
```

Повторный запуск безопасен: выходные Parquet-файлы пересобираются из исходных данных и заменяются атомарно, а строки не добавляются к предыдущему результату. История запусков и обнаруженных схем хранится отдельно.

## Слои хранения

- `data/bronze/` — исходные данные в табличном виде с добавленными полями происхождения.
- `data/silver/` — проверенные измерения PM10, отдельный файл отклонённых строк и нормализованные погодные наблюдения.
- `data/gold/` — справочники станции и времени, а также витрина `mart_pm10_weather.parquet`.
- `data/meta/processing.sqlite` — журнал запусков обработки и история схем входных источников.

## Правила обработки

В расчёт включаются только почасовые измерения PM10 (код загрязнителя 5), в единицах `ug.m-3`, с допустимым признаком Validity 1 или 3 и статусом Verification 1. Значение -999 трактуется как отсутствующее. Записи с недействительными флагами, некорректным интервалом или повторным бизнес-ключом не дублируют итоговый набор.

Все станции сохраняются в Silver. Для Gold используется станция PL0140A в Варшаве: её местоположение соответствует координатам, по которым на предыдущей практике был запрошен погодный ряд Open-Meteo. Погодные данные связываются с измерением по началу часового интервала.

## Изменение схемы

Обязательные поля обоих источников проверяются до обработки. Отсутствие обязательного поля останавливает выполнение. Новые дополнительные поля сохраняются в Bronze и отражаются в истории схем в `processing.sqlite`; в Silver используются только явно заданные поля.
